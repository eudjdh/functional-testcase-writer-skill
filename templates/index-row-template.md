# INDEX 行模板

## 单功能点行

```md
| {序号} | {功能点名称} | {TC数量} | 0 | 0 | [{文件名}]({模块目录}/{文件名}.md) | {负责人} |
```

## 模块小计行

```md
| | **小计** | **{TC合计}** | **0** | **0** | **{总条数}** | |
```

## 模块汇总行

```md
| {模块目录} | {TC} | 0 | 0 | {合计} |
```

## 说明

- `SEC` / `PERF` 列在功能测试阶段固定填 `0`。
- `TC数量` 必须与该功能点文件中实际 `TC-模块缩写-NNN` 的条数一致。
- `小计` 等于该模块各行 `TC` 之和；`总计` 等于各模块小计之和。
- 模块分组新增时，同步在顶部目录追加锚点链接。
- 文件链接使用相对路径，保证在 GitHub 可点击跳转。
