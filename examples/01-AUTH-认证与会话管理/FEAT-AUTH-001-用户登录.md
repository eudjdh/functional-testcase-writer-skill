## 一、功能测试

> 说明：功能测试从产品/用户视角编写，操作步骤仅包含用户可见操作，预期结果仅描述用户可见反馈。用例类型分为：正常流程 / 异常处理 / 边界情况。

### 前置条件

```txt
1. 已打开登录页，env 为测试环境。
2. 已准备一个可正常登录的账号。
```

### 测试数据

```txt
- 正常账号：demo_user / Demo@1234
- 错误密码：Demo@wrong
```

### 功能测试用例

| 项目 | 内容 |
|:---|:---|
| 用例编号 | TC-AUTH-001 |
| 用例名称 | 使用正确账号密码登录成功 |
| 用例类型 | 正常流程 |
| 输入条件 | 登录页可选「账号密码登录」，账号 demo_user 已存在且状态正常 |
| 操作步骤 | 1. 在账号输入框输入 demo_user 2. 在密码输入框输入 Demo@1234 3. 点击「登录」 |
| 预期结果 | 页面跳转到首页，右上角显示当前用户名，页面提示“登录成功” |
