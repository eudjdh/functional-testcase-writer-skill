# INDEX.md 维护

## 是否维护

- 目标仓库存在 `INDEX.md` 时：**新增或修改用例后必须同步**。
- 目标仓库不存在 `INDEX.md` 时：不强制创建，除非用户要求。

## 统计口径

- 只统计实际生成的**功能用例 `TC`** 数量。
- 安全 / 性能空表头**不统计**（除非用户明确要求补充并编号）。
- 计数以「功能测试」章节用例表中的 `用例编号` 为准，不统计 `问题跟踪` 等处的引用。

## 更新步骤

1. 找到对应模块分组表。
2. 更新功能点行：功能点名称、TC 数量、文件链接、负责人（若有）。
3. 更新该模块小计行。
4. 更新底部汇总表中该模块与总计。
5. 若新增了模块分组，同步更新顶部目录锚点。

## 行格式

模块分组表：

```md
| # | 功能点 | TC | SEC | PERF | 文件 | 负责人 |
|:---:|:---|:---:|:---:|:---:|:---|:---|
| 1 | 用户登录 | 12 | 0 | 0 | [FEAT-AUTH-001-用户登录](01-AUTH-认证与会话管理/FEAT-AUTH-001-用户登录.md) | |
| | **小计** | **12** | **0** | **0** | **12** | |
```

- 空表头的 SEC / PERF 列填 `0`。
- 文件链接使用相对路径，可从仓库根或模块目录稳定跳转。

## 一致性

- `TC` 数量应与文件内实际用例数一致。
- 小计等于该模块各行之和。
- 总计等于各模块小计之和。
- 编号重排后，INDEX 中的链接与计数同步更新。
